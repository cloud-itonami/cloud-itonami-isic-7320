## 判断

競合調査レポートの試験価格は **2 USDC**、目標限界利益率は **70%**。
許容総原価は `2 × (1 − 0.70) = 0.60 USDC`。
実原価、需要、成約率、売上は未測定です。販売開始を意味しません。

Exaのmedium/high/x-highはAPI実行あたり0.10/0.50/1.00 USDです。
日本語の完成レポート価格とは直接比較できません。データ追加料金、推論、
検証、保存、運営などを含む当Botの総原価でもありません。
USDとUSDCは別単位であり、この比較は交換レートの実測ではありません。

この価格観測は公式ページを確認して登録したスナップショットです。
常駐価格Botは現在、既定価格と利益率の計算を検証しており、
自動で市場を収集・調査しているわけではありません。
更新時は観測日別CSVを追加し、出典と比較条件を残します。
個人の会話、添付、接続サービスの非公開データはこの公開資料に含めません。

## 保存の現状

- Web Botの会話とプロフィール: Cloudflare D1の`human_bots`。
- 共有Markdown等: D1の`human_bot_files`。所有者単位でアクセスを制限。
- 添付画像・ファイル: Cloudflare R2の`cloud-itonami-drive`。
  所有者のハッシュを含むキーで保存し、認証した所有者のAPIから取得。
- Web Botの推論: Murakumoへ会話・必要な添付・ツール情報を送り、
  回答を会話に保存。`last_run`には最新のモデル名・実行ID等を保存。
  全リクエストの監査ログや内部推論の保存ではありません。
- 専用価格Bot: Durable Objectに`status`と`lastSuccess`を保存。
  計算結果、モデル名、実行ID、時刻、使用トークン数を含みます。
  現在は最新値を上書きするため、全実行の履歴保管ではありません。

以上は2026-09-08に確認した実装です。Murakumo側のログ保持期間、
全ストレージのバックアップ復元・削除期限はこの資料では検証していません。
「推論はMurakumo」と「保存もすべてMurakumo」は異なり、現在の永続保存はCloudflareです。
